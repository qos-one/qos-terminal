# QOS Terminal web demo

The Terminal UI compiled for the browser, talking to a simulated backend instead of the QOS engine. It uses the
same source files as the Terminal (`../src`), with the `demo` feature replacing server functions by HTTP calls
(`../src/api_demo.rs`, generated by `../scripts/gen_api_demo.py`).

Build:

```bash
rustup target add wasm32-unknown-unknown
cp -R ../assets ./assets
dx build --platform web --release
```

The output is under `target/dx/qos-demo/release/web/`. It needs a backend that answers the Terminal's `/api/...` calls;
the hosted live demo on qos.one provides one.
