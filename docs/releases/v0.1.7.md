## Web Terminal v0.1.7

Browser version of the QOS Terminal (WASM client + Linux x86_64 server). Install with `deploy/install.sh` from the engine repo (`QOS_TERMINAL_DOMAIN=...`), see `docs/SELF_HOSTING.md` there. SHA-256 in `qos-terminal-web.sha256`.

A small release that goes with [QOS v0.1.7](https://github.com/qos-one/qos/releases/tag/v0.1.7). Sign-in, orders and the connection to the engine are the same as in v0.1.6.

### Changed

- **Risk → Exposure:** a row's share of gross exposure is shown as a dash when it cannot be worked out in USD or would be above 100%, instead of a wrong percentage (#9).
- **AI notice:** the AI menu and the Risk → AI assistant panel now show the full notice, word for word (#4):

  > Optional and experimental. AI can make mistakes; you are responsible for every order it places. Account data you share goes to your chosen AI provider. Keep your token secret. Software, not financial advice.

- **Demo build only** (`--features demo`, not part of this release's files): no broker sign-in form, no "Switch user" or "Sign out & stop IB Gateway" in the account menu, the GitHub button points to the engine repository, and Strategies → Packages says that backtest and walk-forward results use simulated demo data (#9).

### Documentation

- The README tells new users to start with the engine and links the [Setup report](https://github.com/qos-one/qos/issues/new?template=1_setup_report.yml) form (#10).
